Estudante de Engenharia da Computação, atualmente desenvolvendo minhas habilidades em programação e desenvolvimento web. Estou construindo minha transição para a área de tecnologia por meio de projetos acadêmicos e pessoais, com foco em front-end.

## Projetos em destaque

### Sabor & Saúde Alimentos — site institucional B2B

Site para uma distribuidora de produtos naturais, criado para captar lojistas: apresenta as marcas, um catálogo com mais de 600 itens organizado por categoria, os diferenciais da empresa e o passo a passo de como comprar. Inclui cadastro de lojista via WhatsApp, cálculo de prazo de entrega por CEP e uma área administrativa com login para envio de fotos.

- **Tecnologias:** React · Next.js · TypeScript · Tailwind CSS
- **O que demonstra:** projeto real para um cliente real, organização de conteúdo em arquivos de dados, componentização e interface responsiva
- 🔗 [Ver site](https://sabor-e-saude-site.vercel.app) · [Repositório](https://github.com/nicolasgabrieltomas/sabor-e-saude-site) <!-- repositório privado: torne público ou remova este link -->

### Assembleia de Deus de Capinzal — site institucional

Site completo e acessível para a igreja, com programação semanal e mensal de cultos, lista de congregações, eventos, devocionais, ministérios, galeria e vídeos. Todo o conteúdo é editável a partir de arquivos de dados, sem precisar mexer nos componentes.

- **Tecnologias:** React · TypeScript · Tailwind CSS · Vite · React Router
- **O que demonstra:** roteamento entre páginas, separação entre conteúdo e código, atenção a acessibilidade e responsividade
- 🔗 [Ver site](https://ad-capinzal-site.vercel.app) · [Repositório](https://github.com/nicolasgabrieltomas/ad-capinzal-site) <!-- repositório privado: torne público ou remova este link -->

### Portfólio pessoal

Meu site pessoal, feito do zero em HTML, CSS e JavaScript puros, sem frameworks nem etapa de build. Design system com tokens em CSS, menu mobile, animações por scroll e deploy automático na Netlify.

- **Tecnologias:** HTML · CSS · JavaScript · Netlify
- **O que demonstra:** domínio dos fundamentos da web sem depender de bibliotecas, organização de código em seções e cuidado com detalhes de UI
- 🔗 [Ver site](https://portfolio-nicolastomas.netlify.app/) · [Repositório](https://github.com/nicolasgabrieltomas/Portfolio-web-Nicolas)
